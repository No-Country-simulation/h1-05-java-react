# JustinaIO

JustinaIO es una aplicación web que conecta a médicos y pacientes que necesitan trasplantes, facilitando el intercambio de información crucial. Es una plataforma completamente responsiva diseñada para ofrecer una experiencia de usuario óptima en diversos dispositivos.

## Descripción del Proyecto

JustinaIO es una plataforma que centraliza y facilita la comunicación y gestión de información entre médicos y pacientes. A través de esta herramienta, los médicos pueden acceder a datos críticos sobre sus pacientes, y los pacientes pueden mantenerse informados sobre sus tratamientos y necesidades de trasplante.

## APIs Disponibles

JustinaIO proporciona varias APIs para facilitar el acceso a información relevante:

- **Medicamentos:** Información sobre medicamentos, incluyendo laboratorio, composición, principio activo, y nombre comercial.  
  [API Medicamentos](https://justinaio.vercel.app/api/medicamentos)

- **Municipios de Argentina:** Listado de municipios, comunas y ciudades agrupados por provincias.  
  [API Municipios](https://justinaio.vercel.app/api/municipios)

- **Prepagas y Obras Sociales:** Información sobre seguros médicos y obras sociales en Argentina.  
  [API Prepagas](https://justinaio.vercel.app/api/prepagas)

- **Patologías Médicas:** Lista de enfermedades con códigos identificadores universales.  
  [API Enfermedades](https://justinaio.vercel.app/api/enfermedades)

- **Especialidades Médicas:** Información sobre diversas especialidades médicas.  
  [API Especialidades](https://justinaio.vercel.app/api/especialidades)
